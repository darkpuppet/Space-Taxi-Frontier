# Frontier sprite atlas v1

`frontier-atlas-v1.png` was generated for this project using the built-in `image_gen` tool. It is the original transparent PNG, preserved without editing. `scripts/sprites.gd` selects and trims atlas regions at runtime. Ships use the top row; the three passenger designs each have idle, two waving, and impatient poses. Character poses share a foot anchor and scale to avoid size changes when an arm is raised.

The final generation prompt was:

> Use case: stylized-concept. Asset type: production 2D arcade game sprite atlas for Space Taxi: Frontier. Generate ONE square 1024 by 1024 PNG with REAL TRANSPARENT alpha background. Exact regular 4 columns by 4 rows grid, 16 separate 256x256 cells, no gutters, no grid lines or labels. Every cell contains exactly one centered isolated sprite with transparent padding, no object crossing a cell. Clean polished high-detail pixel art / hand-painted arcade sprite aesthetic, strong dark navy outlines, subtle metallic shading and readable silhouettes, warm amber/cyan/purple palette consistent across the entire sheet. Orthographic SIDE VIEW for a horizontal platform flight game, never top-down or isometric. Row 1 cells left to right: (1) futuristic yellow amber taxi hovercraft facing RIGHT, low wide body, dark panoramic cyan window, little green roof TAXI lamp with no readable lettering, checker stripe, two extended landing skids, no exhaust flames, occupies at most 210x100 pixels centered; (2) same taxi facing RIGHT with cyan brake jets, same body proportions; (3) enemy purple alien flying saucer side profile, wide silver-purple disk with dome, pink navigation lamps, no flame; (4) small red diamond-shaped hunter drone side elevation, cyan central eye, two small fins. Row 2 cells: four FULL BODY animation poses of exactly the SAME friendly human astronaut passenger in an orange space suit and clear domed helmet, boots at SAME baseline y=224 in each cell, head near y=40, width at most 120: idle arms down, waving one arm at shoulder, waving same arm overhead, impatient hands on hips. Row 3 cells: four corresponding full body poses of the SAME cute GREEN alien passenger in a teal travel jacket with small purple carry-on bag, feet same y=224 baseline and head y=40, idle, shoulder wave, overhead wave, impatient arms crossed. Row 4 cells: four corresponding full body poses of the SAME human traveler with dark skin in a cobalt blue spacesuit with yellow trim and clear helmet, feet y=224, head y=40, idle, shoulder wave, overhead wave, impatient checking wristwatch. Each character consistent in design across its four animation cells. No text anywhere, no watermark, no scenery, no cast floor shadow, no background, no border. Center ship sprites within their cells; people must be complete head to toe with consistent scale.

The generator returned a 1280 x 1280 atlas. Runtime regions account for the actual padding and preserve the raised-hand poses.

## Walking passengers

`frontier-walk-v1.png` was generated with built-in `image_gen`, using `frontier-atlas-v1.png` as the character-design reference. Its twelve frames provide four walking poses for each of the three existing passenger designs. The transparent original is preserved intact. `scripts/sprites.gd` trims regions at runtime, anchors their feet, scales them to the idle height, and mirrors them for leftward walking.

Final prompt:

> Use case: stylized-concept. Asset type: transparent production WALK CYCLE sprite atlas for Space Taxi: Frontier. Reference image is the existing character design atlas; match the three passenger characters exactly in costume, head, colors, proportions and polished outlined pixel-art shading. Create ONE transparent PNG atlas with EXACTLY FOUR EQUAL COLUMNS and THREE EQUAL ROWS, twelve full-body isolated sprites. No ships, no idle/waving poses, only WALKING. Row1: brown-haired male astronaut orange suit and clear helmet, navy gloves/boots and backpack. Row2: lime-green antenna alien in teal travel suit carrying a small purple wheeled suitcase. Row3: dark-skinned curly-haired female astronaut blue suit with yellow trim and clear helmet. Each row is FOUR successive WALK CYCLE key poses all FACING RIGHT: contact left foot forward/right foot back; passing feet together with right knee raised; contact right foot forward/left foot back; passing feet together with left knee raised. Arms counter-swing naturally, alien suitcase follows. All sprites head-to-toe, side-view with slight three-quarter head matching reference. Same character height and head size across its four frames; feet at the same baseline within every cell. Each sprite CENTERED IN ITS OWN EQUAL CELL with 15% transparent padding on every side. Rows must have identical heights and ample gap so heads never cross cell boundaries. Consistent boots, backpacks and accessories across poses. Actual alpha transparency outside objects, no shadows, no ground plane, no text, no border, no labels. Clean readable walking silhouettes with distinct separated legs in contact poses.
