# Cylindrical glass elevator sprites

Generated with the built-in image_gen tool using the existing props and taxi/passenger atlases as style references. The original RGBA output is preserved as `frontier-elevator-v1.png` (1254 x 1254). No alpha removal, recoloring, or raster postprocessing was applied.

`scripts/passenger_arrivals.gd` registers the rear shell and three front-door poses separately. It draws the passenger between those layers, blends the door poses, reduces the front glass opacity while retaining solid metal caps, and clips source pixels at the pad surface during deployment and retraction. The frame's mechanical base extends inside the pad. Lifts remain exclusive to expected and ongoing drop-offs.
