# Menu typography

- `Limelight-Regular.ttf`: Limelight, by Nicole Fally / Sorkin Type, used for Art Deco titles. [Upstream source](https://github.com/google/fonts/tree/main/ofl/limelight). License: `Limelight-OFL.txt`.
- `JosefinSans.ttf`: Josefin Sans variable font, by Santiago Orozco and the Josefin Sans Project Authors, used for geometric button lettering at weight 600. [Upstream source](https://github.com/google/fonts/tree/main/ofl/josefinsans). License: `JosefinSans-OFL.txt`.

Both fonts are distributed under the SIL Open Font License 1.1. Original font files and license notices are included unchanged. Normal gameplay copy and the split-flap scoreboard retain their existing readable fonts.
